# MathXY

## Overview

A program that helps students with math, specifically with algebra and geometry. It includes an AI that helps you understand said topics and gives you problems for you to solve. **MathXY** allows you to input a topic and it will swiftly give you the explanation and the overview of said topic.

This program helps is focused on Pisay students who struggle on math especially grade 8 students with Math a, b (a.k.a Algebra, and Geometry). You can save your topics in a built in file system so you wont lose track of your progress. Since it is powered by Ai, it can make custom shortcuts or quick solutions for long problems with a minimal margin of error. 

##Features

A free Python-based AI that takes a plain
algebra or geometry question and shows every step. No sign-up,
no subscription.

- Solve algebra problems (equations, factoring, simplification)
- Solve geometry problems (area, distance, angles, intersections)
- Show every step, not just the final answer
- Keep it free and simple, no sign-up required

- A simple interface (CLI or web) instead of raw terminal input
- Step-by-step explanations for factoring and solving equations
- Drawing geometry shapes so you can *see* the triangle/line
- Saving past questions so you can review them later
- Supporting more problem types (quadratics, circles, etc.)


## How to run the program

1. Open your browser and search "Github".
2. Search for a program file labelled "MathXY" and save it.
3. then open python 3 and run the file.
4. then they will be  in a dashboard and to search for a topic they can type the topic in the search bar.
5. and there will be choices on top whether they want to see the equations, description of the topic or problems of the topic.
6. then if they get confused they can ask the ai chat log at the side

## Input needed

1. Ai chat prompts
2. User Search Queries
3. Navigation choices
4. Problem Answers
5. File management actions

## Sample Output

A user confused on a certain topic in math they can go to MathXY then search for the topic then they will read the descriptions, equations and sample problems of the topic to better understand it and can ask in the ai chat log for some concerns/questions about the topic and they can advance to different topics after they mastered the previous one.
